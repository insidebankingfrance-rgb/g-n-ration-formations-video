# Photo du présentateur virtuel

Dépose ici la photo qui servira de base à l'avatar IA (ex: `presentateur.jpg`).

Recommandations (exigées par D-ID pour un bon résultat) :
- Visage de face, bien centré, yeux ouverts, bouche fermée au repos
- Bon éclairage, fond neutre
- Résolution correcte (au moins 512x512), format JPG ou PNG
- Une seule personne visible sur la photo

Renseigne ensuite le chemin dans `.env` via `AVATAR_IMAGE_PATH`.
